# Component 2: AI-Powered Water Fraud & Anomaly Detection\n\nThis directory contains the machine learning models and training assets for Non-Revenue Water (NRW) and physical bypass fraud detection in the Kaduwela water distribution network.\n\n## Models\n- `models/isolation_forest.joblib`: Unsupervised anomaly detector trained on baseline pressure/flow residuals.\n- `models/random_forest.joblib`: Supervised multi-class anomaly classifier (normal, leak, bypass fraud).\n- `models/random_forest_v2.joblib`: Calibrated high-precision model for operational deployment.\n
